# PRODUCT REQUIREMENTS DOCUMENT (PRD)

## 1. Project Name

**Internal Helpdesk/Support Ticketing System**

## 2. Problem Statement

Employees may face technical problems such as computer, software, network, or system issues.
It can be difficult to track and manage these problems without a proper support system.

## 3. Objective

The system allows employees to create support tickets and helps the support team track and resolve them.

## 4. Target Users

* Employees
* Support Staff
* Admin

## 5. Main Features

* Create a support ticket
* View tickets
* Search tickets
* Update ticket status
* Assign tickets to support staff
* Delete tickets
* Track resolved and pending tickets

## 6. Ticket Details

Each ticket can contain:

* Ticket ID
* Employee Name
* Issue Title
* Description
* Category
* Priority
* Status
* Date
* Assigned Support Staff

## 7. Ticket Status

* **Open** – New issue
* **In Progress** – Support team is working on it
* **Resolved** – Issue has been fixed
* **Closed** – Ticket is completed

## 8. Technology

* **Frontend:** HTML, CSS
* **Backend:** Python Flask
* **Database:** MySQL

## 9. Basic Workflow

**Employee → Create Ticket → Support Team → Update Status → Resolve Issue → Close Ticket**

## 10. Expected Result

The system provides a simple way to report, manage, track, and resolve internal support issues in one place.
